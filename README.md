# Case Okiar Intelligence - Análise de Dados do Buenos Drivers App

Este projeto foi desenvolvido como parte de um desafio prático da Okiar Intelligence, utilizando uma base de dados com 200 registros relacionados ao Buenos Drivers, um aplicativo de corrida.

O trabalho teve como objetivo explorar os dados disponíveis e investigar oportunidades para o melhoria no aumento de corridas.

## Desenvolvimento

O trabalho foi organizado nas seguintes etapas:

1. **Exploração dos dados:** reconhecimento da estrutura da base e das variáveis disponíveis.
2. **Preparação dos dados:** organização e tratamento das informações para análise.
3. **Análise exploratória:** investigação de padrões e comportamentos presentes nos dados.
4. **Análise estatística:** aplicação de métodos estatísticos para investigar associações entre variáveis.
5. **Interpretação:** avaliação dos resultados e identificação de possíveis oportunidades.
6. **Apresentação:** organização das descobertas em uma apresentação de resultados.

## Tecnologias e ferramentas

- Python
- Pandas
- NumPy
- Pingouin
- PowerPoint para a apresentação
